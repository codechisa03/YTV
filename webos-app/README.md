# IPTV Live TV - LG webOS Application

A modern, high-performance IPTV streaming application designed specifically for **LG webOS Smart TVs**, featuring full support for the **LG TV Remote Control**, channel switching with **CH+ / CH-**, direct number dialing, 10-foot TV UI, and preloaded iptv-org playlists.

## Features
- **TV Remote Control Channel Changing**:
  - `CH+` / `CH-`: Switch to next / previous live channel with on-screen OSD banner.
  - `0 - 9`: Direct channel number dialing (e.g., press `5` to jump straight to channel 5).
  - `OK / Enter`: Open visual Channel Guide & EPG drawer.
  - `D-Pad`: Up/Down navigation through channel cards and Left/Right category switching.
  - `Red / Green / Yellow / Blue`: TV color button shortcuts for Favorites, Categories, Aspect Ratio, and Settings.
  - `Magic Remote`: Full air-mouse pointer and click support.
- **10-Foot Living Room Interface**:
  - OLED deep-black styling with glowing focus borders for remote navigation.
  - Channel OSD banner showing channel number, logo, name, category, stream resolution, and live clock.
  - Channel number dial overlay with countdown timer.
  - Category filters: All, News, Sports, Movies, Music, Kids, Entertainment, Favorites.
- **Robust Video Streaming**:
  - Powered by HLS.js with webOS-tuned buffer settings for smart TV stability.
  - Automatic error recovery and stream status notifications.
- **Playlists**:
  - Preloaded curated streams from `iptv-org`.
  - Built-in category feeds and country playlists (US, UK, India, Germany, France, etc.).
  - Custom M3U / M3U8 URL input support.
- **Testing & Packaging**:
  - Built-in local HTTP server with interactive Virtual Remote on PC.
  - Official webOS `appinfo.json` and `.ipk` build configuration.
